Metric definitions

Precision@K = relevant recommended / K

Recall@K = relevant recommended / total relevant

NDCG@K = DCG@K / IDCG@K

MAE = (1/n) Σ |yᵢ − ŷᵢ|

RMSE = √[(1/n) Σ (yᵢ − ŷᵢ)²]

Protocol: 25 % of every viewer's ratings are held out (seeded). “Relevant” = held-out rating ≥ 4.
